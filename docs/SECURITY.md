# 安全说明

## 信任边界

- 浏览器与 App 都不可信。所有权限、可见性、状态迁移由服务端判定。
- 客户端版本门禁只是体验层，真正拦截在服务端 `X-App-Version` 校验。
- 管理操作先写审计再提交业务变更；审计写入失败则整体回滚。

## 密钥

| 密钥 | 用途 | 轮换影响 |
|---|---|---|
| `SESSION_PEPPER` | 会话令牌哈希 | 全员重新登录 |
| `DATA_ENCRYPTION_KEY` | 树洞身份映射 AES-256-GCM | 需保留旧版本密钥解密历史数据 |
| `TREE_IDENTITY_HMAC_KEY` | 限流与封禁假名、日志 IP 关联 | 历史假名失效，不影响内容 |
| `CLASS_GATEWAY_PEPPER` | 班级口令哈希 | 全班重新输入口令 |

密钥只来自环境变量，不写入仓库、镜像、日志或前端产物。

## 匿名与追溯

- 树洞正文与身份映射分表存放；普通接口永不返回身份。
- 身份映射使用 AES-256-GCM，逐行 nonce 与密钥版本。
- 仅总管理员可调用揭示接口；每次揭示写入审计，包含操作者、时间、目标与请求上下文。
- 按约定不通知当事人，也不要求填写理由；审计记录不可由管理员删除。
- 限流与封禁使用 `HMAC(user_id)`，避免明文身份进入缓存键与日志。

## 日志

- 不记录密码、Cookie、Authorization、请求体、树洞正文。
- 精确 IP 与 UA 加密存储，另用独立 HMAC 做关联分析。
- HTTP 明细 60 天、语义事件 90 天；归档失败保留源数据，不提前清理。
- 日志读取接口仅总管理员可用，且自身也写入审计。

## 并发与滥用

- 三级令牌桶：100 毫秒、1 秒、60 秒，账号读写与登录分别计数。
- 全局在途请求上限与有界等待队列，超限快速失败并返回 `Retry-After`。
- 数据库连接池上限 8，语句超时 2 秒。
- 图片直传 U3，不经过 Node 进程；服务端只做流式校验，不做转码。
- 登录失败持久化计数，连续失败锁定，成功即清零。
- IP 维度限流仅在能确认可信客户端地址时启用，且阈值宽松，避免整栋教学楼共用出口时误伤。

## 客户端

- APK 固定发布证书签名，启动时校验签名证书指纹与资源摘要。
- 更新包下载后校验 SHA-256 与签名一致性，不符即拒绝安装。
- 加速源只是镜像，清单与安装包内容以 GitHub Release 与哈希为准。
- 不把“请求签名密钥”嵌入 APK；它必然可被提取，不构成安全边界。

## 上报

发现漏洞请直接联系总管理员，不要在公开渠道披露可利用细节。
